## What's new in 2.1.0
- Update notice: NEXORA tells you when a newer version is out (once a day, can be turned off; it only reads the public release list on GitHub)
- Every release is now built and tested automatically on Windows, macOS and Linux
- Secondary grading on the Color page: pick a colour, limit it with an ellipse or rectangle window, check it with Show matte
- One-click 9:16, 1:1 and 4:5 versions of an edit (Export page), with the original left untouched
- Clip speed presets, track height S / M / L, curves, stills with wipe compare, right-click clip menu with colour labels
